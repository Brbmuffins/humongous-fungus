# Hammy's voice

Drop recordings here and they play when Hammy says that kind of line. Name each
file after the kind of line, with a number if there's more than one:
`fart.m4a`, `fart-2.m4a`, `toilet-1.mp3`. Any of mp3, m4a, aac, ogg, wav or webm.
Keep each one short (1–3 seconds) and quiet at the start, so they don't clip.
