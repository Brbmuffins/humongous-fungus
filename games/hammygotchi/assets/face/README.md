# Cube Hammy's face

Cube Hammy uses drawn eyes and lips until these exist. Add any of them and the
game uses the photo instead:

| File | What |
|---|---|
| `eyes.png` | Both eyes, cut out on a transparent background, looking straight ahead |
| `mouth.png` | Mouth closed |
| `mouth-open.png` | Mouth open (optional; used while he talks and eats) |

PNG or WebP. Crop tight around the eyes or the mouth; the game sizes them to the
cube. Straight-on photos in even light work best. Blinking, squinting and
surprise are done by squashing the eye photo, so open, relaxed eyes are best.
